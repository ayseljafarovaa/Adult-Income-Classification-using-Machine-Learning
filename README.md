# 💰 Adult Income Classification using Machine Learning

This repository contains a machine learning project aimed at predicting whether an individual's annual income exceeds $50,000 based on demographic, educational, and employment-related features using the UCI Adult Income dataset.

## 📊 Project Overview
The pipeline includes:
* **Data Preprocessing & Cleaning:** Handling missing values (`?`), stripping whitespace, and encoding target variables.
* **Feature Engineering & Selection:** Dropping redundant features and applying One-Hot Encoding (`pd.get_dummies`) to categorical attributes.
* **Feature Scaling:** Standardizing numerical features using `StandardScaler`.

## ⚙️ Models Implemented
The following classification algorithms were trained and evaluated:
* **Logistic Regression**
* **Support Vector Classifier (SVC)**
* **Decision Tree Classifier**
* **Random Forest Classifier**
* **Gaussian Naive Bayes**
* **K-Nearest Neighbors (KNN)**

## 📈 Evaluation Results & Comparison
Models were evaluated using Accuracy Score, Precision, Recall, and F1-Score. A horizontal bar chart visualizes and compares the accuracy of all implemented models.

## 🛠️️ Tech Stack & Libraries
* **Python** (3.13+)
* **Pandas & NumPy** (Data manipulation)
* **Scikit-learn** (Preprocessing, metrics, and machine learning models)
* **Matplotlib & Seaborn** (Data visualization & plotting accuracy comparisons)
